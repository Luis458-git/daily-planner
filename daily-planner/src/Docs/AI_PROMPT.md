## Referencia visual oficial

El diseño visual de Daily Planner YA ESTÁ DEFINIDO.

Dentro de la carpeta `reference/` existe el archivo ZIP de referencia de la aplicación.

Este ZIP contiene las pantallas oficiales que deben utilizarse como referencia:

* Dashboard principal
* Rutina semanal
* Temporizador y descansos
* Administrar actividades
* Estadísticas y progreso

También contiene archivos `screen.png` y `code.html`.

### Reglas importantes

* NO inventar un diseño nuevo.
* NO cambiar el estilo visual general sin autorización.
* Utilizar los `screen.png` como referencia visual principal.
* Utilizar los `code.html` solamente como apoyo para comprender estructura, estilos y distribución.
* Adaptar el diseño correctamente a React.
* NO pegar todo el `code.html` directamente dentro de `App.jsx`.
* Dividir la interfaz en componentes React reutilizables.
* Mantener consistencia visual entre todas las páginas.
* Mantener tamaños, espaciados, tarjetas, navegación, tipografía y distribución lo más similares posible a las referencias.
* Si una funcionalidad nueva no aparece en el diseño original, integrarla respetando el mismo lenguaje visual.
* No modificar los archivos originales de `reference/`.

El objetivo es reproducir el diseño proporcionado y posteriormente agregar la funcionalidad real utilizando React.
